# Petshop da Ponte / BeckerSys — instaladores

Este repositório contém somente arquivos de distribuição dos aplicativos. O código-fonte do ERP permanece privado.

Baixe os instaladores em [Releases](https://github.com/sapohaha-cell/petshop-da-ponte-atualizacoes/releases/latest).

- Android: `Petshop-da-Ponte-Mobile-release.apk`.
- Windows PDV: `BeckerSys-pdv-VERSAO-setup.exe`.
- Windows Clínica: `BeckerSys-clinica-VERSAO-setup.exe`.
- Windows Gestão: `BeckerSys-gestao-VERSAO-setup.exe`.

Instale a primeira versão com o atualizador por cima da instalação existente. As versões futuras são verificadas quando o aplicativo abre. Salve o trabalho antes de reiniciar para aplicar uma atualização.

As atualizações Android distribuídas pelo Expo precisam ser compatíveis com o APK instalado. Mudanças nativas exigem um novo APK. Os instaladores Windows deste fluxo não têm assinatura de editor.

Os arquivos de hash permitem conferir a integridade dos instaladores. Os arquivos `.yml` e `.blockmap` são usados automaticamente pelos aplicativos Windows.
